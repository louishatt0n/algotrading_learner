# Learning Bible

This Learning Bible is a structured course companion for this repository.
It is written in an A-level textbook style: educational, instructive, and step-by-step.

## How To Use This Book

1. Read chapters in order.
2. In each lesson, study:
   - Learning objectives
   - Key terms
   - Core explanation
   - Worked examples
   - Check your understanding
   - Stretch section
3. Try the commands and examples yourself.

## Reading Order

1. `01_The_Boring_Stuff`
2. `02_Python`
3. `03_Trading_Bots`
4. `04_Advanced_Quantitative_Trading`

## Who This Is For

This material is aimed at a learner with limited Python and trading experience, moving from beginner foundations toward confident intermediate practice.
