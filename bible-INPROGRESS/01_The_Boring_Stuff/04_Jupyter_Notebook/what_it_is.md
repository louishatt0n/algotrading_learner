# Jupyter Notebook: What It Is

## Key Terms

- **Cell**: Executable block of code or markdown.
- **Kernel**: Runtime process executing notebook cells.

## Core Explanation

Jupyter Notebook is an interactive environment for writing code in small steps, viewing outputs immediately, and combining narrative text with analysis.

## Worked Example

Use a notebook to load `btc_daily.csv`, compute returns, and visualize distributions before moving logic into `.py` scripts.
