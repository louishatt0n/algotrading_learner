PYTHON INTERPRETER AND ENVIRONMENTS (BEGINNER GUIDE)
====================================================

What is a Python interpreter?
- It is the program that runs Python code (python.exe on Windows).

Why imports sometimes fail:
- Different interpreters have different installed packages.
- If terminal uses Interpreter A but debugger uses Interpreter B, imports can fail in one place and work in another.

HOW TO CHECK WHICH INTERPRETER IS RUNNING
-----------------------------------------
In a Python script:
import sys
print(sys.executable)
print(sys.version)

In terminal:
python --version
python -m pip --version

BEST PRACTICE
-------------
Run + Debug + pip install should all use the SAME interpreter/environment.

EXAMPLE WORKFLOW
----------------
Step 1:
Select interpreter in your editor (Python: Select Interpreter).

Step 2:
Install packages with that interpreter:
python -m pip install numpy pandas matplotlib scikit-learn

Step 3:
Run the script and verify imports.

Step 4:
Debug the same script and verify behavior is identical.

CONDA VS VENV VS DOCKER
-----------------------
- conda env: useful for local data/science workflows
- venv: lightweight Python virtual environment
- Docker: full runtime packaging (Python + deps + startup command)

For deployment:
- Docker usually reduces interpreter mismatch problems.
