TROUBLESHOOTING CHEATSHEET
===========================================

PYTHON / IMPORTS
----------------
Problem:
ModuleNotFoundError in debug but not terminal.

Cause:
Different interpreter/environment.

Fix:
- Select same interpreter for run/debug/editor.
- Install with: python -m pip install ...

DOCKER DAEMON
-------------
Problem:
failed to connect to docker API / pipe not found

Cause:
Docker Desktop engine not running.

Fix:
- Start Docker Desktop
- wait for engine running

DOCKER BUILD
------------
Problem:
docker build requires 1 argument
Fix:
Add build context path:
docker build -t IMAGE_NAME .

Problem:
Dockerfile cannot be empty
Fix:
Wrong file picked or wrong working directory.
Use project root command `docker build -f dockerfile -t testbot .`
or from `tooling` use `docker build -f ../dockerfile -t testbot ..`.

DOCKER RUN
----------
Problem:
pull access denied

Cause:
Image not present locally with that name/tag.

Fix:
Build first and check with docker images.

Problem:
container name already in use
Fix:
docker rm OLD_CONTAINER_NAME
Then run again.

JUPYTER + SSH TUNNEL
--------------------
Problem:
connection failed / connection refused

Common causes:
- Jupyter not running
- wrong port mapping
- typo in command
- nested SSH confusion

Fix checklist:
1) Start Jupyter on VPS and note actual port.
2) Tunnel local 8888 to that exact remote port.
3) Open http://127.0.0.1:8888
4) Use token from jupyter notebook list

SSH
---
Problem:
authenticity warning first time
Fix:
Verify fingerprint, then type yes.

Problem:
Permission denied (publickey)
Fix:
Wrong key/user context or nested SSH from inside server.
