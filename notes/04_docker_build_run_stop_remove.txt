DOCKER COMMANDS YOU USED (STEP BY STEP)
=======================================

1) BUILD IMAGE
--------------
From the learning project root:
docker build -f dockerfile -t testbot .

If you are currently in tooling:
docker build -f ../dockerfile -t testbot ..

Important:
- The final "." is required (build context path).

2) LIST IMAGES
--------------
docker images

3) RUN CONTAINER
----------------
docker run -d --name testbot_c --restart unless-stopped testbot:latest

Notes:
- image = testbot:latest
- container name = testbot_c

4) SEE RUNNING CONTAINERS
-------------------------
docker ps

See all (including stopped):
docker ps -a

5) VIEW LOGS
------------
docker logs testbot_c

6) STOP CONTAINER
-----------------
docker stop testbot_c

7) START EXISTING CONTAINER
---------------------------
docker start testbot_c

8) REMOVE CONTAINER
-------------------
docker rm testbot_c

Force stop + remove:
docker rm -f testbot_c

9) REMOVE IMAGE
---------------
docker rmi testbot:latest

If image "in use":
- remove related containers first, then remove image.

COMMON ERRORS YOU HIT
---------------------
Error: docker build requires 1 argument
Fix: add "." at end of build command.

Error: Dockerfile cannot be empty
Fix: wrong file selected or wrong working directory.
Use project root with -f dockerfile, or from tooling use -f ../dockerfile and context ..

Error: pull access denied
Fix: image not built locally yet, or wrong image name.

Error: container name already in use
Fix: remove/rename old container first.
